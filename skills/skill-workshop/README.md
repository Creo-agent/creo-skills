# skill-workshop

| Field | Value |
|---|---|
| **Folder** | `skills/skill-workshop/` |
| **Purpose** | Create a new Creo skill from scratch, or improve an existing one based on what was learned running it. The goal: skills that get sharper every time they're used, not ones that stay frozen at first-draft quality. |
| **Triggers** | "Create a new skill for X", "Improve the resize skill", "List all skills", "/skill-workshop create", "/skill-workshop improve" |
| **Keywords** | `skill`, `create skill`, `improve skill`, `skill workshop`, `new skill`, `skill-workshop` |
| **Outputs** | A new or updated `skills/<name>.md` file following the quality checklist. |
| **Dependencies** | None — reads and writes the `skills/` directory. |
| **Entry point** | Load `SKILL.md` |
| **Owner** | Elior Siegelwachs |
| **Last updated by** | Creo-agent |
