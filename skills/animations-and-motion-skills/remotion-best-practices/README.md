# Remotion Best Practices

Domain-specific knowledge for building videos with Remotion (video creation in React), organized
as a `rules/` library of focused topic files plus a thin router — so Remotion work in this hub has
a single authoritative, load-on-demand reference without leaving the repo.

## Key files

`SKILL.md` (thin router) · `PROMPT.md` (how to use the rules + full index) · `rules/` (37 topic
`.md` files: animations, timing, sequencing, transitions, compositions, assets, captions, audio,
charts, 3D, maps, voiceover, and more) · `rules/assets/` (reusable `.tsx` component examples) ·
`NOTICE` (attribution)
