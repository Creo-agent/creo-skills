# Skill: resize-with-nano-banana

Generate AI-produced ad format variants from a Master Key Visual using the Nano Banana Pro API. Same size catalog and layout rules as the native Figma resize skill — but outputs are standalone PNG files generated by the model, not Figma frames.

## When to use this skill
- Someone asks to resize / generate banner sizes using Nano Banana or AI
- Source design is in Figma or attached as an image
- Output should be PNG files (not Figma frames)

---

## Pre-Flight Setup

```bash
# 1. Load API key
export GEMINI_API_KEY=$(grep -E "^GEMINI_API_KEY=" /Users/creativeagent/slack-claude-agent/.env | cut -d= -f2 | tr -d '"' | tr -d "'")

# 2. Verify ImageMagick (required for exact pixel dimensions)
which magick || which convert

# 3. Confirm source: either a Figma URL or an image in .slack-uploads/
```

If GEMINI_API_KEY is empty or ImageMagick is missing, stop and surface the error.

## Step 1: Get Source Image

**From Figma URL:** Call `mcp__figma-write__get_screenshot`, then:
```bash
curl -sL -o /tmp/master-kv-source.png "SCREENSHOT_URL"
```
Also run `mcp__figma-write__get_design_context` in parallel for design analysis.

**From Slack attachment:** Copy from `.slack-uploads/FILENAME` to `/tmp/master-kv-source.png`.

---

## Step 2: Build Source Design Brief

Analyze the source image/design context and record:
- Dimensions, background (hex/gradient)
- Brand colors (primary, secondary, accent)
- Logo position (top-left / centered / etc.)
- Headline: approx size, color, weight, sample text
- Hero visual: position and approximate size in frame
- CTA button: shape, color, label text
- Any third-party brand logos present (Gmail, Slack, Asana, etc.)

Keep this brief in context — it feeds every Nano Banana prompt below.

## Step 4: Execute — One Size at a Time

### Before each size, ask:
> "Ready to generate **[size]** ([W]×[H]). Include a CTA button? (Default: [Yes/No]) / Button text? / Button color? / Anything to exclude?"

Wait for answers, then:

### 4a: Build the prompt

```
Adapt the attached master key visual to [Size Name] format ([W]×[H], placement: [DV/STORY/FB/LI]).

KEEP EXACTLY: all text content unchanged, monday.com logo, brand colors ([colors from brief]),
all gradients/shadows/opacity effects, third-party brand names: [list].

SOURCE DESIGN:
[Paste Source Design Brief]

ELEMENTS TO INCLUDE: [Logo / Headline / Visual / CTA per user answer]
[If CTA:] CTA text: "[text]", color: [color], solid fill only.
[If exclusions:] Do NOT include: [excluded elements].

TARGET LAYOUT RULES:
[Paste the per-size layout block below]

OUTPUT: Finished ad-ready design, aspect ratio [API ratio], no placeholders, safe zones respected.
```

### Per-size layout blocks

**Billboard 970×250 DV**
> Extremely wide short banner. Logo + CTA grouped vertically on RIGHT. Headline LEFT-CENTER (max ~40px). Visual anchored LEFT filling height. Full 970px width, 20px safe zones, 30px between headline and right group.

**Leaderboard 728×90 DV**
> Extremely wide, only 90px tall — simplify ruthlessly. Logo + CTA stacked on RIGHT. Headline LEFT-CENTER one phrase max (max ~22px). Visual FAR LEFT. 15px safe zones. Text max 70% of banner height.

**Medium Rectangle 300×250 DV**
> Compact near-square. Dark footer (50–60px) at bottom for Logo + CTA side-by-side. Headline + visual in upper section. 15px safe zones.

**Half Page 300×600 DV**
> Narrow tall column: Logo → Headline → Visual → CTA (top to bottom). Visual ≥ 35–45% height. 30px logo→headline, 25px headline→visual. 15px safe zones.

**Skyscraper 160×600 DV**
> Very narrow. Logo TOP. Text stacked vertically beneath (can wrap). Visual MID/LOWER (≥40% height). CTA near BOTTOM. 15px safe zones. Simplify — 160px is tight.

**Story 1080×1920 STORY**
> META SAFE ZONES ENFORCED: top 269px clear, bottom 403px clear, left/right 65px margins. Usable: x 65–1015, y 269–1517. Logo top of usable area. Headline below logo (40px gap). Visual fills majority. NO content outside usable area.

**Facebook Feed 1080×1350 FB**
> Tall portrait. Logo TOP (30px from edge). Headline → Visual → CTA top to bottom. Visual ≥ 40–50% height. Even distribution across 1350px. 30px safe zones.

**LinkedIn Feed 1200×1200 LI**
> Square, centered, professional. Logo TOP or TOP-LEFT. Visual CENTER prominently. Headline clearly placed. 30px safe zones. Text can be larger for LinkedIn feed visibility.

### Hard constraints (all sizes):
- Never alter text content — reduce font size if needed, never rewrite
- One logo in master = one in output (never duplicate)
- Third-party brand names stay in exact English form
- CTA: solid fill, single-line label
- No rotation, no distortion, no element cropping
- Gradients/shadows/opacity preserved from source

### 4b: Call the API

```bash
export GEMINI_API_KEY=$(grep -E "^GEMINI_API_KEY=" /Users/creativeagent/slack-claude-agent/.env | cut -d= -f2 | tr -d '"' | tr -d "'")

node << 'EOF'
const fs = require('fs'), https = require('https');
const imageData = fs.readFileSync('/tmp/master-kv-source.png').toString('base64');
const prompt = `PROMPT_TEXT`;       // substitute constructed prompt
const payload = JSON.stringify({
  model: "gemini-3-pro-image",
  input: [
    { type: "text", text: prompt },
    { type: "image", data: imageData, mime_type: "image/png" }
  ],
  response_format: {
    type: "image", mime_type: "image/png",
    aspect_ratio: "RATIO",    // e.g. "9:16"
    image_size: "SIZE"        // e.g. "2K"
  }
});
const options = {
  hostname: 'generativelanguage.googleapis.com',
  path: '/v1beta/interactions', method: 'POST',
  headers: { 'Content-Type': 'application/json', 'x-goog-api-key': process.env.GEMINI_API_KEY, 'Content-Length': Buffer.byteLength(payload) }
};
const req = https.request(options, res => {
  let d = ''; res.on('data', c => d += c);
  res.on('end', () => {
    const j = JSON.parse(d);
    const imgData = j.output_image?.data || j.steps?.flatMap(s => s.content || []).find(b => b.type === 'image')?.data;
    if (imgData) { fs.writeFileSync('/tmp/nb-output-raw.png', Buffer.from(imgData, 'base64')); console.log('OK'); }
    else { console.error('FAIL:', d.substring(0, 300)); process.exit(1); }
  });
});
req.on('error', e => { console.error(e.message); process.exit(1); });
req.write(payload); req.end();
EOF
```

Error handling: 429 → wait 10s retry; 400 → rephrase prompt retry; 503 → tell user, offer retry.

### 4c: Post-process to exact dimensions

```bash
magick /tmp/nb-output-raw.png -resize WxH^ -gravity Center -extent WxH /tmp/nb-output-final.png
magick identify /tmp/nb-output-final.png   # verify
```
